## O que é JavaScript?

JavaScript é a linguagem de programação da web. Roda em navegadores, servidores (Node.js), aplicações mobile, desktop e IoT. É **dinâmica**, **multi-paradigma** e evolui anualmente via ECMAScript.

## Por que aprender em 2026?

- Domina 98% dos sites do mundo.
- Ecossistema gigante: React, Vue, Svelte, Node, Deno, Bun.
- Curva de aprendizado amigável para iniciantes.
- Salários competitivos e demanda constante.

## Seu primeiro código

```javascript
const saudacao = (nome) => `Olá, ${nome}! 🚀`;
console.log(saudacao('dev'));
```

::tip::Use o DevTools (F12 → Console) como laboratório. Testar trechos curtos é a forma mais rápida de fixar sintaxe.::end::
